Ash Studio Recorder

Record your screen, then edit it. Zoom, cursor and backgrounds are applied after recording, so nothing is baked in.

Download from GitHub Releases View source
  • Records displays and windows, with separate camera, microphone and system audio tracks (system audio on Windows).
  • Input events are saved with the video, so the cursor and clicks can be restyled later.
  • Automatic zoom from clicks, with spring easing and manual edits.
  • Backgrounds, padding, face cam, keystroke overlay, speed ramps, trim and cuts.
  • Export to MP4, WebM or GIF. Everything stays on your computer.
